💧 Sistema de Consumo de Água
Sistema desenvolvido em Python para classificar o perfil de consumo de água de imóveis e apresentar alertas educativos aos moradores.

🎯 Objetivo
O programa recebe o tipo de imóvel e o consumo mensal de água em m³ e classifica o consumo de acordo com regras predefinidas.

📋 Regras de classificação
🏢 Comercial: tarifa comercial aplicada.
🌱 Apartamento abaixo de 10 m³: consumo econômico.
🏠 Apartamento ou casa até 25 m³: consumo moderado.
⚠️ Demais situações: consumo excessivo.
▶️ Como executar
Tenha o Python 3.10 ou superior instalado.
Abra o terminal na pasta consumo-agua.
Execute:
python app.py
Informe o tipo de imóvel.
Informe o consumo mensal em m³.

📚 Conceitos utilizados
Entrada de dados com input()
